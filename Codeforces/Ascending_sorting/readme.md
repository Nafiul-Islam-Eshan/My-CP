# Sort Numbers
## Problem Link: https://codeforces.com/group/MWSDmqGsZm/contest/219158/problem/T

### <u>Algorithm:</u>
1. Take three numbers a, b, c and a temp variable for swaping numbers
1. Make an array ` nums ` of 3 numbers a, b, c, in order to print them as same as input order.
1. If a > b, then swap their value. 
1. If b > c, then swap their value.
1. Again check if a > b, then swap their value. 
1. print a, b, c respectively.
1. print the values of nums array using index, like nums[0]
